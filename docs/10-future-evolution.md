# Future Evolution

## Phase 0: Conceptual Harness

Use this repository to align on terminology, boundaries, failure modes, and demo scenarios.

## Phase 1: Shared Contracts And Traces

Introduce request and response contracts, sensor result shapes, trace IDs, and provider-neutral attempt records.

## Phase 2: Common Sensors And Evals

Add shared schema, citation, policy, latency, and cost sensors. Build offline eval datasets from real workflow risks.

## Phase 3: Repair, Retry, And Fallback Policies

Centralize failure vocabulary and corrective actions. Add controlled repair and provider fallback for proven cases.

## Phase 4: Cross-Workflow Harness Services

Extract common services only after Writer and QC workflows reveal repeated needs.

## Phase 5: Selective Autonomous Workflows

Support more autonomous flows only where policy, evidence, contracts, traces, and human boundaries are mature.
