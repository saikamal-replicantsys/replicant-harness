# What We Build Now

The near-term implementation should stay lightweight.

Recommended foundations:

- provider interface
- structured contracts
- validation hooks
- trace IDs
- prompt and guide versioning
- eval datasets
- sensor result format
- centralized failure vocabulary

## Why This Scope

These pieces create immediate reliability benefits without forcing RepliSense into a large orchestration architecture. They also make real failure patterns visible so later abstractions can be earned.
