# SOP Compliance QC Guide

- Use only supplied approved rules.
- Never create a finding without a ruleId.
- Never invent a rule.
- Never reference pending or rejected rules.
- Never invent source SOPs.
- Every finding must identify target evidence.
- Distinguish absence from contradiction.
- Do not claim content is missing unless supplied target context is sufficient to establish absence.
- Preserve exact numbers and units.
- Do not exaggerate severity.
- Do not create duplicate findings for the same violation.
- Explain expected versus observed.
- Output structured JSON only.
- Do not include chain-of-thought or hidden reasoning.
